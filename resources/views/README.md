# Chacha Prime UI

UI is designed as an original premium Chacha Prime storefront and unified admin experience.

Design direction:
- Responsive mobile-first layout
- Premium navy / electric-blue foundation with restrained warm accent
- Strong product imagery and clear price hierarchy
- Retail, wholesale and group-buy prices shown contextually
- Accessible controls, keyboard focus states and reduced-motion support
- Customer and admin interfaces share the brand system without sharing navigation

Brand assets belong under `public/assets/brand/`.
